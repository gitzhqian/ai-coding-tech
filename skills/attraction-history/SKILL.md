# 领域专业知识
# 景点历史解说开发流程

1. 读取当前景点名称、城市和现有数据结构。
2. 检查项目中是否已有景点解说相关接口和页面组件。
3. 后端优先调用 Qwen API 生成：
   - 历史沿革
   - 趣味典故
   - 必看亮点
   - 游览贴士
4. 如果模型调用失败，提供本地降级说明。
5. 前端采用可展开/收起的面板展示。
6. 修改完成后：
   - 运行 Python 语法检查
   - 检查 lint
   - 验证页面交互
7. 不修改与本功能无关的代码。
